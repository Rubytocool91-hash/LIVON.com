Live-data note: DEXScreener exposes public token-profile and pair endpoints. Pump.fun's current coin-data API is CORS-protected, so a browser-only file cannot safely call it directly; the production version needs a small backend proxy. This dashboard therefore identifies Pump.fun/PumpSwap candidates through indexed DEX data and keeps trading in paper mode. DEXScreener documents 60 requests/min for profile/boost endpoints and 300 requests/min for pair/token endpoints.
